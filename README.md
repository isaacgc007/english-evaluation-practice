# English Evaluation Practice — Days 1–10

An original practice app with 73 phonics questions, speaking prompts and ten reading passages. Includes 21 marked phonics stretch questions.

[Open the practice app](https://isaacgc007.github.io/english-evaluation-practice/)

[Parent question-and-answer review](https://isaacgc007.github.io/english-evaluation-practice/parent-review.html)

Progress is saved only in the current browser; it does not sync across devices. Audio uses browser speech synthesis. Handwriting, speaking and reading aloud are checked by a grown-up.

This is the first ten days of a planned 30-day programme. No private school documents or personal practice records are included.
